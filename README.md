# KLEERO Landing

Conversion-focused landing page for **kleero.co** — an AI cost-savings assistant for small restaurants (WhatsApp + Telegram).

Built with **Next.js 14** + **TypeScript** + **Tailwind CSS** + **next-intl**. Mobile-first. Two languages (EN, ES) with auto-detection. Deploy target: **Vercel**.

## Design system

| Token              | Value                                       |
|--------------------|---------------------------------------------|
| Background         | `cream-100` `#FAF7F2` (warm off-white)      |
| Primary text       | `forest-700` `#0E2C22` (deep forest green)  |
| CTA / accent       | `terracotta-500` `#D26A3C` (warm orange)    |
| Display font       | **Fraunces** (serif, characterful)          |
| Body font          | **DM Sans** (clean, friendly, not Inter)    |
| Texture            | Subtle SVG paper-grain overlay              |

The aesthetic is **warm editorial F&B** — opposite of generic SaaS. Built for food-truck owners and immigrant entrepreneurs who don't want a "corporate" feel.

## i18n strategy

- `/` → English (default, no prefix)
- `/es` → Spanish
- Auto-detection from `Accept-Language` header (handled by `next-intl` middleware)
- User choice persists in URL (no localStorage needed)
- Adding **Russian** later: open `src/i18n/routing.ts`, add `'ru'` to `locales`, then create `src/messages/ru.json` + add `RU` button in `LanguageSwitcher.tsx`.

## CTA tracking (UTM)

All CTA links flow through `src/lib/links.ts`:

```ts
telegramLink('landing_hero')   // → t.me/kleero_demo_bot?start=landing_hero
whatsappLink('landing_cta')    // → wa.me/447348941867?text=Hi%20KLEERO%20landing_cta
```

UTM source codes used:
- `landing_hero` — top of page
- `landing_compare` — comparison section
- `landing_referral` — referral block
- `landing_cta` — bottom of page

The bot already parses `start=...` and writes it to Supabase. Done.

## Deploy to Vercel + connect kleero.co — step by step

### Step 1 — Create a GitHub repo

1. Go to [github.com](https://github.com) → click **+** (top right) → **New repository**
2. Name: `kleero-landing`
3. Public or Private — doesn't matter (Vercel free tier supports both)
4. Don't tick README / .gitignore (we have them)
5. Click **Create repository**

### Step 2 — Upload code to GitHub

**Easiest way (browser, no terminal):**

1. On the empty repo page, click **uploading an existing file**
2. Open the unzipped `kleero-landing/` folder
3. **Select all files inside** (not the folder itself — the contents) and drag them into the GitHub upload area
   - ⚠️ Make sure hidden files like `.gitignore` are included (toggle "show hidden files" in your OS)
4. Commit message: `Initial commit`
5. Click **Commit changes**

**Alternative (Codespace, like you used for the bot):**

```bash
git clone https://github.com/YOUR_USER/kleero-landing.git
cd kleero-landing
# copy files in
git add .
git commit -m "Initial commit"
git push
```

### Step 3 — Connect Vercel

1. Go to [vercel.com](https://vercel.com) → **Sign in with GitHub**
2. **Add New** → **Project**
3. Find `kleero-landing` in the list → **Import**
4. Framework: **Next.js** (auto-detected — leave it)
5. Root directory: `./` (default)
6. Build command: `npm run build` (default)
7. Output directory: leave default
8. Environment variables: **none needed**
9. Click **Deploy**

Wait ~2 minutes. You'll get a URL like `kleero-landing-xyz.vercel.app`. Open it. The site should work.

### Step 4 — Connect kleero.co (GoDaddy DNS)

1. In Vercel: **Project** → **Settings** → **Domains**
2. Type `kleero.co` → click **Add**
3. Vercel will say something like "Set the following records on your DNS provider":
   - **Type:** `A`  •  **Name:** `@`  •  **Value:** `76.76.21.21`
   - **Type:** `CNAME`  •  **Name:** `www`  •  **Value:** `cname.vercel-dns.com`
   *(Exact values shown by Vercel — copy from their UI, don't trust this README blindly.)*
4. Open a new tab → [godaddy.com](https://godaddy.com) → log in
5. Top right → your name → **My Products**
6. Find `kleero.co` → click **DNS** (or the three dots → **Manage DNS**)
7. You'll see a list of existing DNS records. **Delete or edit:**
   - The existing `A` record on `@` (Name = `@`) — change its value to `76.76.21.21`
   - The existing `CNAME` on `www` — change its value to `cname.vercel-dns.com`
   - If GoDaddy has "Parking" or "Forwarding" records — disable them
8. **Save**
9. Go back to Vercel — within 5–30 minutes (sometimes up to 2 hours) the domain status will turn green
10. Visit `https://kleero.co` — should work with HTTPS automatically (Vercel auto-issues a Let's Encrypt cert)

**Tip:** GoDaddy sometimes sets a 1-hour TTL by default. If propagation seems slow, that's why — just wait it out. You can check propagation status at [whatsmydns.net](https://whatsmydns.net) (enter `kleero.co`, type `A`).

### Step 5 — Verify everything

Open `https://kleero.co` and check:
- [ ] Hero loads with the phone mockup
- [ ] Language switcher in top right toggles EN ↔ ES
- [ ] Visiting from a Spanish browser auto-redirects to `/es`
- [ ] All CTAs open WhatsApp/Telegram with the correct UTM
- [ ] Mobile view (DevTools or real phone): no horizontal scroll, buttons are tappable
- [ ] Run [PageSpeed Insights](https://pagespeed.web.dev/?url=https%3A%2F%2Fkleero.co) — aim for 90+ on mobile

## Customisation cheat sheet

**Change colors:** `tailwind.config.ts` → `theme.extend.colors`

**Change copy:** `src/messages/en.json` and `src/messages/es.json`

**Change bot links / phone numbers:** `src/lib/links.ts`

**Add the Russian language:**
1. `src/i18n/routing.ts` → add `'ru'` to `locales`
2. Copy `src/messages/en.json` → `src/messages/ru.json`, translate
3. `src/components/LanguageSwitcher.tsx` → add `{ code: 'ru', label: 'RU' }` to `LOCALES`
4. Add `'ru'` to type assertions in `Hero.tsx` and `HowItWorks.tsx` (the `useLocale() as 'en' | 'es'` lines)

**Replace SVG bot mockups with real screenshots:** see `public/screens/README.txt`

**Add Google Analytics / Meta Pixel** (later):
- Install `@next/third-parties` package
- Add `<GoogleAnalytics gaId="G-XXX" />` inside `[locale]/layout.tsx` body

- Video demo (not produced yet)
- Blog / About / Careers

## Tech notes

- **No client-side JS for the marketing content** — everything except the language switcher is server-rendered. Page loads fast on 3G.
- **Edge runtime** for OG image generation — Vercel handles it for free.
- **Fonts loaded via `next/font`** — zero layout shift, self-hosted on Vercel CDN.
- **No analytics dependencies** — track conversions via UTM source codes that arrive in the bot → Supabase.
- Built mobile-first; desktop is the secondary view (Instagram/Facebook ad traffic is ~95% mobile).
